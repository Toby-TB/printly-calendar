# 🗓️ 拾光行事历 · 月历打印工坊

一个月视图行事历 Web 应用：以「星期为列、日期为网格」，支持 DIY 风格与预设模板，
并针对**打印 + 打孔装订成册**做了专门设计。

## 快速开始

纯静态网页，无需安装、无需构建：

1. 直接双击打开 `index.html`；或
2. 起一个本地静态服务器（可选）：
   ```bash
   python3 -m http.server 8080
   # 浏览器访问 http://localhost:8080
   ```

日程数据保存在浏览器 `localStorage`，可导出 / 导入 JSON 迁移。

## 语言切换

右上角下拉菜单支持三种语言，切换即时生效，界面、日历、打印页全部同步翻译：

- 简体中文
- 繁體中文
- English

语言偏好会自动保存，下次打开沿用上次选择；首次打开会尝试跟随浏览器语言。

## 功能清单

### 📋 日程管理
- 月视图：7 列星期 × 6 行日期网格，可切换「周一 / 周日」起始
- 今天高亮、周末底纹、相邻月份日期淡化
- 点击日期添加日程；点击色条编辑 / 删除
- 支持：标题、开始日期、结束日期（跨天）、时间、分类颜色、备注
- 分类图例：内置 6 类，可自定义新增 / 删除，点击图例可隐藏该分类
- 侧栏「本月日程」快速浏览与编辑

### 🎨 DIY 设计
- 8 套预设模板：奶油手账 / 抹茶清新 / 莫兰迪 / 复古牛皮纸 / 樱花粉 / 午夜蓝 / 极简白 / 海盐蓝
- 自定义：主色、纸张背景、纹理（波点 / 方格 / 横线 / 斜纹 / 星点）、字体、圆角、背景图片
- 元素开关：打印装订孔标记、装饰角标、网格线、周末底纹
- 所有设置即时生效并自动保存

### 🖨 打印装订
- **选择日期范围**：起始月 + 结束月，快速选「本年度」「未来 12 个月」
- 范围中的每个月生成一页 A4（可预览逐页检查）
- **每页顶部自动预留 26mm 装订区**，并有虚线引导 + 可选两个打孔标记（圆钉 / 装订圈位置）
- 可选首页封面（封面标题、范围月份高亮）
- 底部备注区、页码
- 打印页使用当前 DIY 主题（颜色 / 纹理 / 背景图），建议打印时开启浏览器「背景图形」
- 支持跨天日程在打印页连续标注

## 使用提示

- 打印前先点「打印预览」核对页数；Chrome 打印设置中选 `A4 / 纵向 / 边距：无 / 背景图形：开启`
- 打孔位置默认两个圆孔，圆心距左右各 65mm（A4 标准两孔装订位），顶部 10.5mm
- 封面在「打印」面板中可关闭；封面标题可自定义
- 模板切换会重置自定义颜色 / 纹理（背景图也会移除），先选模板再微调更省事
